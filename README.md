# PackageDependencies

Консольное приложение на языке Go для анализа и визуализации графа зависимостей npm-пакетов.

## Возможности

- Настройка параметров анализа через командную строку.
- Получение информации о зависимостях npm-пакетов.
- Построение графа транзитивных зависимостей.
- Определение порядка загрузки пакетов.
- Визуализация графа с помощью D2.
- Вывод зависимостей в виде ASCII-дерева.

## Структура проекта

- `src/` — исходный код приложения.
- `tests/` — тесты приложения.
- `run.bat` — запуск в Windows.
- `run.sh` — запуск в Linux.

## Запуск

Windows:

```powershell
.\run.bat --package lodash --repository https://registry.npmjs.org
```

Linux:

```bash
./run.sh --package lodash --repository https://registry.npmjs.org
```
## Этап 2. Сбор данных

На данном этапе реализовано получение информации о зависимостях npm-пакетов напрямую из репозитория.

Программа выполняет следующие действия:
- Отправляет HTTP-запрос к указанному репозиторию npm.
- Получает метаданные пакета в формате JSON.
- Определяет последнюю опубликованную версию пакета.
- Извлекает список его прямых зависимостей и требования к их версиям.
- Выводит зависимости в алфавитном порядке.
- Обрабатывает ошибки сетевых запросов, HTTP-ответов и декодирования JSON.

Для получения данных используются стандартные библиотеки Go. Менеджеры пакетов и сторонние библиотеки для получения информации о зависимостях не используются.

Пример запуска:

```powershell
.\run.bat --package express --repository https://registry.npmjs.org
```

Для Linux:

```bash
./run.sh --package express --repository https://registry.npmjs.org
```
## Параметры командной строки

- `--package` — имя анализируемого пакета.
- `--repository` — URL репозитория или путь к тестовому файлу.
- `--test-mode` — режим тестового репозитория.
- `--ascii-tree` — вывод зависимостей в виде ASCII-дерева.
- `--max-depth` — максимальная глубина анализа.

## Этапы разработки

1. Прототип командной строки и проверка параметров.
2. Получение непосредственных зависимостей npm-пакетов.
3. Построение графа транзитивных зависимостей.
4. Определение порядка загрузки пакетов.
5. Визуализация графа зависимостей.
